# Taxi Fare Prediction - Machine Learning Project

## Overview
This project is a machine learning exercise focused on predicting taxi fares using regression models. It is part of my learning path in Machine Learning and Data Science.

---

## Objective
The objective is to build a regression model that predicts `fare amount` based on trip-related features.

---

## Dataset
The dataset used contains pre-processed taxi trip data with features such as:
- Trip distance
- Time-related features
- Payment type
- Other engineered variables
